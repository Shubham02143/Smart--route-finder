      How Dijkstra's Algorithm Works

      1. Set the source city's distance to zero.
      2. Select the city with the smallest known distance.
      3. Examine connected roads and update shorter distances.
      4. Continue until the destination's shortest distance is found.
      5. Reconstruct the route using the recorded previous cities.

      About This Project

      This project demonstrates Dijkstra's shortest-path algorithm using a weighted graph of cities and road distances. Python performs the calculation, Flask connects the algorithm to the website, JavaScript updates results without a page reload, and SVG visualizes the selected route. When traffic mode is on, busy roads get a higher weight, so the algorithm can choose a longer but faster route. Every search is saved in an SQLite database.
